# Realism audit, November 2026

Working files for the audit of Rainbows, Vesicle fusion, Japanese maple and Engine against real
physics. Nothing here is part of the site, and this branch is not meant to be merged.

- `physical-expectations.md`: what each scene should show, written before any frame was recorded.
  The GitHub issues cite its tags (`ENG-C5`, `RB-B6`, `VES-A4`, `MAP-C5`).
- `frames/`: the pictures and short clips the issues link to. Recorded in headless Chromium with
  software WebGL, at 1280 × 800 and at 390 × 844 at twice the sharpness.

The issues link to these files by commit, so keep this branch while they are open.
